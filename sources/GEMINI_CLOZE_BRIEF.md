# [의뢰] TOPIK/KIIP 문맥 예문(Cloze) 대량 생성 — Gemini 20 병렬

영어권 학습자가 한국어를 배우는 앱의 **문맥 빈칸 채우기(cloze)** 학습 데이터를 생성합니다.
(말해보카의 예문 학습을 방향만 뒤집음: 영어 문장·상황 제시 → 한국어 문장의 빈칸에 들어갈 한국어 단어를 맞힘)

## 1. 대상
- 전체 어휘 목록: `image_mapping.json` (6,701 고유 단어; `korean, pos, hanja, gloss(gloss_out.json), topik_level, kiip_level`)
- 단어당 **2~3개**의 cloze 예문 생성 → 약 15,000~20,000 문항
- **초급(TOPIK A / KIIP 1·2단계) 우선**

## 2. 출력 스키마 (단어당 예문 1개 = 아래 객체 1개; 2~3개면 배열로 여러 개)
```jsonc
{
  "korean": "차",                                  // 대상 단어(그대로)
  "situation_en": "Asking a coworker to finish a task",  // 상황(영어, 짧게)
  "sentence_ko": "해당 업무는 차주까지 전달 부탁드립니다.",  // 단어를 실제로 쓰는 자연스러운 한국어 문장
  "sentence_en": "Please hand over this task by next week.", // 정확한 영어 번역
  "blank": "차주",                                  // 문장에서 가릴 정확한 표면형 — sentence_ko의 부분문자열이어야 함
  "distractors_ko": ["지난주", "금주", "내년"]        // 오답 3개(그럴듯하지만 틀린 한국어 단어)
}
```

## 3. 필수 규칙 (품질 게이트)
1. **`blank`는 `sentence_ko`의 정확한 부분문자열**이어야 함 (마스킹 가능해야 함). 자연스러운 표면형 우선 (차→"차주", 활용/파생 반영).
2. **`sentence_ko`는 해당 레벨 난이도의 자연스러운 실사용 문장**, 대상 단어가 실제로 등장.
3. **`sentence_en`은 정확한 번역** (직역 아님, 자연스럽게).
4. **`distractors_ko` 3개**: 빈칸 자리에 문법적으론 들어갈 수 있으나 뜻이 틀린 실제 한국어 단어. **정답의 유의어 금지, 중복 금지, blank와 동일 금지.** 품사·길이·격식 유사.
5. `hanja`·`gloss`로 **정확한 뜻**을 잡을 것 (동음이의어 주의). **틀린 gloss(예: 감사→thanksgiving)는 올바른 뜻으로 교정하여 예문 작성.**
6. 부적절/모호한 단어는 **자연스러운 최선의 예문**을 만들되, 정말 불가능하면 스킵(빈 배열).

## 4. 산출물 형식 & 위치
- 입력을 20청크로 분할 → 20 에이전트 병렬.
- 출력: 청크별 JSON 배열 파일 → `C:\Users\JY\Desktop\dash2zero\sources\cloze_out\chunk_XX.json`
- 각 배열 원소는 위 스키마 객체. (한 단어에 예문 2~3개면 같은 korean으로 객체 여러 개)
- 완료 후 "넣었어요" 회신 → 우리가 검증(blank 부분문자열·중복·길이) 후 병합·업로드.

## 5. 우리 쪽 자동 검증 (통과 못 하면 재생성 요청)
- `blank` ⊂ `sentence_ko` 여부
- `distractors_ko` 3개, 정답/중복 아님
- 필수 필드 존재
